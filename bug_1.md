# Баг: Форма принимает спецсимволы в поле «Имя»

## Описание
При вводе спецсимволов и цифр в поле «Имя» форма не показывает ошибку.

## Шаги воспроизведения
1. Открыть форму "Contact Sales"
2. Ввести в поле «Имя»: `""""23123@@@`
3. Заполнить остальные поля
4. Нажать "Talk to an app expert"

## Ожидаемый результат
Форма показывает ошибку: "Введите корректное имя".

## Фактический результат
Форма принимает значение и отправляет заявку.

## Severity
Medium

## Priority
Medium
