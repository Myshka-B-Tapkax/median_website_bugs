# Баг: Форма принимает спецсимволы в поле 'Фамилия'

## Описание
При вводе спецсимволов и цифр в поле «Фамилия» форма не показывает ошибку.

## Шаги воспроизведения
1. Открыть форму "Contact Sales"
2. Ввести в поле «Фамилия»: `@@@@`
3. Заполнить остальные поля
4. Нажать "Talk to an app expert"

## Ожидаемый результат
Форма показывает ошибку: "Некорректно введённая фамилия"

## Фактический результат
Форма принимает значение и отправляет заявку

## Severity
Medium

## Priority
