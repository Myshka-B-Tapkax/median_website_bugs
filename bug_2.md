# Баг: В форме поле 'email' не валидируется

## Описание
При вводе кириллицы в поле 'email' форма не показывает ошибку.

## Шаги воспроизведения
1. Открыть форму "Contact Sales"
2. Ввести в поле «email»: `авв@mil.ru`
3. Заполнить остальные поля
4. Нажать "Talk to an app expert"

## Ожидаемый результат
Форма показывает ошибку: "Некорректный email"

## Фактический результат
Форма принимает значение и отправляет заявку

## Severity
Medium

## Priority
High
